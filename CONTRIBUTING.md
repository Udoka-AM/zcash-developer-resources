# Contributing to Zcash Developer Resources

Thank you for helping keep the Zcash developer ecosystem accurate and production-ready!

## Guidelines
1. **Verify Maintenance Status:** Only submit tools, SDKs, or RPC endpoints compatible with active Zcash network upgrades (NU6 / NU7+).
2. **Flag Deprecations:** If a resource relies on legacy `zcashd` RPCs or transparent-only (`t-addr`) flows, explicitly label it.
3. **Formatting:** Follow `- [Project Name](https://url) - Concise technical description of what it does and who it is for.`
4. **Pull Requests:** Keep PRs focused—one category or resource per commit where possible.
